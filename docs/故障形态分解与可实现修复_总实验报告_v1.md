# 胸片分类器：故障形态的分解与可实现修复

## 总结

本项目最初试图验证一个“质量感知路由 Agent”假设：Hard QC、Soft QC、U-MultiClass 不确定性和异构模型分歧，能否在固定人工复核预算下，把更容易出错的胸片送入二次模型或人工复核，从而降低选择性分类风险。

目前的完整证据不支持把质量感知路由作为主要贡献。质量特征在部分困难分层中可以解释模型失效，甚至在置信度已经失效时提供额外信息；但在固定复核预算的直接决策评价中，增益小且不稳定，不能证明其具有稳定的部署价值。项目因此转向更明确的问题：

> 胸片分类器的失效可以分解为可通过操作点重定位修复的决策层故障，以及任何阈值或温度后处理都无法消除的排序层故障；同时，合成降质和校准指标都可能制造关于系统安全性的错误印象。

当前证据支持四个贡献方向：

1. **操作点坍缩的刻画与零标注修复**：在先验发生变化而排序能力尚存时，冻结模型并按目标患病率重定位阈值，可以修复决策层故障。这里的“零标注”是指不使用目标域逐例标签，但仍需要目标患病率或其无标签估计。
2. **排序层残差的不可修复性**：操作点修复后，真实翻拍条件仍比干净条件高出约 0.193 的决策代价，并伴随约 0.170 的 AUROC 下降；该差距不能由进一步调阈值消除。
3. **ECE 与决策代价的反例**：ECE 或 NLL 最优的温度可能降低校准误差，却同时降低灵敏度，甚至选择出近似全阴性的退化分类器。因此校准报告必须同时给出 TPR、预测阳性率、代价和退化基线。
4. **合成降质的代理失效与评估陷阱**：降质施加分辨率不一致、以模型自身分数构造软错误目标、来源差异造成的平凡可分，都可以让质量路由看起来有效。真实配对降质必须作为独立验证。

## 1. 项目演进

### 1.1 初始 Agent 阶段

目标疾病为 Cardiomegaly，基础模型为 DenseNet-121 + U-MultiClass，输出 negative、uncertain、positive 三类概率。Model 2 使用 ResNet-50 + U-MultiClass，作为结构异质的二次模型。初始 Agent 包含 Hard QC、Soft QC、`p_uncertain`、模型置信度门控、模型分歧和简单融合。

这一阶段完成了：

- CheXpert-v1.0-small 数据下载、解压、manifest 构建和 Frontal 筛选；
- 患者级划分、U-MultiClass 训练、温度缩放和逐样本路由轨迹保存；
- Hard QC、Soft QC、`p_uncertain` 与模型分歧的诊断；
- route-validation 与 official-valid 的 coverage-risk、ECE、Brier 和 Bootstrap 分析。

初始结果显示：`p_uncertain` 与错误率没有稳定的独立单调关系；Model 2 在 route-validation 的被调用子集上有互补性，但在 official-valid 的被调用子集上反而更差；简单 Fusion 没有稳定优于 DenseNet-121。由此，Model 2、Fusion 和 `p_uncertain` 均不适合作为主 Agent 策略。

### 1.2 患者级分层缺陷与修复

旧版 `make_agent_split.py` 先按患者众数标签排序，再对全局列表切片，导致 calibration、route-validation 和 model-selection 的患病率约为 2%–3%，而 pooled train 的映射阳性率约为 12.2%。这会污染 temperature、checkpoint 选择和 coverage cutoff，因此旧结果统一标记为 `invalid_split_diagnostic`。

修复版 `stratified_patient_split_v2` 在患者标签层内独立随机分配：

```text
model_train       70%
calibration       10%
route_validation  10%
model_selection   10%
official_valid    保留官方划分
```

修复验收结果：

- 所有训练相关 split 两两患者交集为 0；
- official-valid 与训练患者交集为 0；
- seed=42 和 seed=7 的训练相关 split 映射阳性率约为 11.65%–12.29%；
- 每个 split 的偏差小于 1.5 个百分点；
- official-valid 的患者和图像集合保持不变。

### 1.3 修复后 CheXpert Agent 基线

修复后重新训练 DenseNet-121 和 ResNet-50，分别在 calibration 集拟合温度，并在 route-validation 上选择 75% coverage 工作点。严格二分类 AUROC 和 Binary ECE 只在 `label ∈ {negative, positive}` 的样本上计算，不把 uncertain 当作 negative。

| Seed | Split | Known rows | DenseNet AUROC | DenseNet Binary ECE |
|---:|---|---:|---:|---:|
| 42 | route-validation | 17,816 | 0.8440 | 0.0201 |
| 42 | official-valid | 202 | 0.8289 | 0.1809 |
| 7 | route-validation | 18,388 | 0.8440 | 0.0335 |
| 7 | official-valid | 202 | 0.8307 | 0.1838 |

修复后温度为：

| Seed | DenseNet-121 | ResNet-50 |
|---:|---:|---:|
| 42 | 0.494342 | 0.542644 |
| 7 | 0.442687 | 0.768727 |

在 75% coverage 工作点，route-validation 风险为 6.09%（seed42）和 6.55%（seed7），official-valid 实际 coverage 为 80.69% 和 81.19%，风险为 22.09% 和 20.73%。这表明修复后风险迁移仍然存在，但不能再归因于原来的患者级划分污染。需要强调：official-valid 只有 202 张图像，风险区间较宽，不能据此宣称精确的临床风险水平。

## 2. 合成降质实验：质量感知假设的边界

### 2.1 正确的推理管线

最终采用设计 A：先把图像缩放到模型输入的 224×224，再在这张图上施加降质；模型和 QC 特征读取同一张图。旧设计 B 在 320×320 上施加降质，再缩放到 224，导致模型实际受到的降质与 QC 测量的降质不一致。

受控对照表明，同一图像、同一模型、同一噪声参数，仅改变降质发生的分辨率，`noise_010` 的 AUROC 可以从 0.4751 变为 0.8122，而 `quality_risk` 仅从 0.3750 变为 0.3760。由此得到一个工程性约束：降质实验必须在模型实际消费的分辨率上执行，QC 也必须在同一张输入张量上计算。

### 2.2 结果

在设计 A 的 13 个降质条件上：

- 最差条件下错误率从约 0.13 上升到约 0.84，AUROC 从 0.844 下降到约 0.721；
- 置信度检测错误的能力在低对比和强噪声条件下降到约 0.50，接近随机；
- 质量特征加入模型置信度后的梯度提升增量平均为 +0.0330，13/13 个条件为正；
- 该增量与“置信度检测错误的 AUROC”呈负相关，`r = -0.73`；置信度越失效，质量特征越有机会提供额外信息；
- 但这只是条件内的诊断性证据，不等于质量特征在固定复核预算下能稳定改善路由。

### 2.3 温度与操作点

在四组设置和多个策略比较中，ECE 或 NLL 优化的温度通常会降低校准误差，但可能牺牲 TPR，甚至增加 TPR=0 的条件数。相反，按目标患病率进行阈值重定位，可以在不改变样本排序的情况下直接修复操作点。该修复不保证 cost-optimal，也不适用于排序已经崩溃的条件；它只解决“分数位置错了”而不解决“病例排序错了”。

### 2.4 质量路由的直接结论

固定人工复核预算的比较中，质量特征加入 confidence router 的额外代价收益很小且不稳定：六个设置中五个 95% 区间跨 0，唯一排除 0 的效应约为 0.14 个百分点。因而：

- 可以保留质量特征作为故障解释和分层诊断；
- 不应把质量特征宣称为已被验证的逐图路由器；
- “质量感知路由有效”不再作为论文主假设。

## 3. NIH ChestX-ray14 外部验证

NIH 官方 test 划分包含 25,596 张图像、2,797 名患者，Cardiomegaly 患病率为 4.18%。标签来自报告 NLP，不与 CheXpert 的放射科医生判读完全等价；因此它是跨机构、跨设备和跨标注体系的外部压力测试，而不是测量等价性证明。

冻结源域温度和阈值后：

| 指标 | 结果 |
|---|---:|
| AUROC | 0.7045 |
| 错误率 | 0.3569 |
| TPR | 0.6183 |
| 预测阳性率 | 0.3668 |
| ECE | 0.1579 |
| FN:FP=2:1 代价 | 0.3728 |

模型仍有跨机构排序能力，但预测阳性率是目标患病率的 8.8 倍，说明阈值位置严重失配。使用目标患病率匹配阈值后，代价下降到 0.1044；然而 TPR 下降到 0.1665。这不是分类能力提升，而是把操作点调整到目标先验，并诚实暴露模型剩余的排序能力边界。

按真实质量分层后，质量增量与置信度失效之间的负相关在 NIH 上重现；但整库 `quality_risk` 与置信度比较的差异 Bootstrap 区间跨 0。因此 NIH 支持“质量信号可以解释某些域外故障”的诊断结论，不足以支持“质量信号是稳定路由器”的部署结论。

## 4. CheXphoto 配对真实降质验证

CheXphoto valid 提供同一批 202 张正面胸片的四种条件：本地干净原图、手机真实翻拍、合成翻拍和合成数字降质。图像和标签逐图配对，能够消除病例组成差异。

主要结果：

| 条件 | AUROC | 错误率 | ECE | 代价 |
|---|---:|---:|---:|---:|
| 干净原图 | 0.8288 | 0.2624 | 0.1883 | 0.5198 |
| 真实翻拍 | 0.6592 | 0.3267 | 0.2368 | 0.6535 |
| 合成翻拍 | 0.8133 | 0.2822 | 0.1992 | 0.5594 |
| 合成数字 | 0.8104 | 0.2475 | 0.1637 | 0.4851 |

真实翻拍相对干净原图的 AUROC 差为 -0.1696，95% CI 为 [-0.2564, -0.0967]；合成翻拍和合成数字的 AUROC 差分别为 -0.0155 和 -0.0184，区间跨 0。换言之，合成降质在这个配对实验中没有复现真实翻拍的排序层损失。

冻结分数并按目标患病率匹配阈值后，真实翻拍代价从 0.6535 降到 0.5050，TPR 从 0 恢复到 0.4848；但仍明显差于干净原图修复后的 0.3119，残差约 0.193。这是排序层信息损失的实证下界，而不是进一步调阈值可以消除的误差。

几何 TTA 将真实翻拍上的阳性标签 AUROC 从 0.605 提高到 0.669，但固定分数后的层内 AUROC 仅为 0.537，接近随机；固定复核预算下最好的可实现组合 AURC 为 0.487，所有增益的 Bootstrap 区间均重叠。因此 TTA 的正确定位是有限的诊断性补救，不是已证实的主路由方案。

CheXphoto 还撤回了两类早期结论：QC 特征以 AUROC=1.0 区分真实与合成图像，主要是 RGB 灰度存储造成的色度伪影；QC 以 AUROC=1.0 区分干净原图与真实翻拍，主要是来源和全局强度范围可分，而不是临床质量可分。

## 5. 统一故障分解

### 5.1 决策层故障：可实现修复

当目标先验变化而模型仍能维持一定排序能力时，固定阈值会导致预测阳性率偏离目标患病率。阈值重定位或等价的先验偏移可以恢复一个合理操作点，且不需要目标域逐例标签。报告中用 TPR、预测阳性率、错误率和非对称代价共同判断修复是否有效，而不是只看 ECE。

### 5.2 排序层故障：后处理不可修复

真实翻拍导致 AUROC 的显著下降和修复后仍存在的 0.193 代价残差，说明模型表征或输入鲁棒性已经受损。任何只对 logits 做温度、截距或阈值变换的方法都保持样本排序，不能消除这部分损失。要修复排序层，需要更强模型、代表性训练数据、适配真实采集链路的增强，或重新设计表征。

### 5.3 评估层故障：指标和代理可能误导

ECE/NLL 可能在模型退出工作时变好；软错误 `1-p(y)` 含有 p 自身，直接用 p 或与 p 同向的信号评估它会产生循环性；合成降质若在错误分辨率施加，则参数不能代表模型实际受到的扰动；来源、颜色和强度差异也会制造“质量检测”假象。

## 6. 当前论文应主张什么

建议主标题改为：

> **Repairable and Irreducible Failures of Chest-Radiograph Classifiers: Operating-Point Collapse, Ranking-Layer Loss, and Evaluation Traps**

论文主线不再是“提出一个有效的质量感知路由器”，而是：

1. 用四个域把分类器失效拆成操作点层和排序层；
2. 给出仅需要目标患病率估计的操作点修复，并报告其适用边界；
3. 用配对真实降质证明修复后仍有排序层残差；
4. 用 ECE 反例、分辨率对照和 p 耦合诊断，说明为什么常见评估流程会高估系统安全性。

“质量特征”在论文中保留为诊断变量和方法学对照，不作为主方法，不宣称临床质量真值，也不宣称能稳定降低人工复核成本。

## 9. 自审结论

- **贡献**：有效贡献是故障分解、操作点修复和评估陷阱，而不是质量路由性能提升。
- **证据**：CheXphoto 的配对真实降质和 NIH 的跨机构结果支持主线；外部数据仍只有两个来源，不能宣称普遍规律。
- **术语**：统一使用“操作点层”“排序层”“决策代价”“目标患病率匹配阈值”；避免把所有后处理都称为“校准修复”。
- **限制**：单标签 Cardiomegaly、单一主模型、CheXphoto n=202、NIH 标签体系不同、FN:FP=2:1 仍是占位设定。
- **不可支持的表述**：不要写“质量感知路由已被证明有效”“ECE 改善代表临床风险降低”“合成降质可代表真实降质”“零标注不需要任何目标域统计量”。
