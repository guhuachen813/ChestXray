# 胸部 X 线质控门初版方案

## 1. 目的与边界

本模块用于判断胸部 X 线是否适合进入自动分类流程，并在质量风险较高时建议人工复核。模块不进行自主诊断，不替代放射科医生，也不把质量分数解释为疾病概率。

核心研究问题：

> 在疾病分类置信度相近的情况下，加入图像质量状态，能否更准确地识别不适合自动处理的胸片，从而降低选择性风险？

第一版只研究“质量检测 + 拒诊/升级”，不加入失败恢复、VLM 复核、TTA 或强化学习。

## 2. 质量标签

### 2.1 第一版标签

采用二分类：

```text
quality_label = 1：适合自动分类
quality_label = 0：不适合自动分类，建议人工复核
```

标注依据参考 Hu 等人的胸片诊断质量研究，重点观察：

- 肩胛骨明显覆盖肺野；
- 肺野或肋膈角缺失；
- 明显伪影、导管或外部物体遮挡；
- 严重旋转、锁骨不平坦或体位不合适；
- 严重过曝、欠曝、模糊或压缩导致诊断信息不足。

“勉强可用”病例第一版可以单独记录，但训练时暂时并入“不适合自动分类”或作为存疑样本，不直接做三分类。

### 2.2 标注数量与抽样

建议从 CheXpert 中抽取 400–550 张正面胸片：

- 300–400 张用于训练和验证；
- 100–150 张作为独立质量测试集；
- 按患者划分，不能让同一患者出现在不同集合；
- 尽量覆盖不同疾病标签、正常图像、AP/PA 体位和不同质量水平。

如果只有一名医生可标注，应保留“标注不确定”字段；如果有两名标注者，报告 Cohen’s kappa，并由导师或高年资医生解决分歧。

## 3. 质控门结构

```text
输入胸片
   |
   v
免费硬筛：前景比例、动态范围、尺寸/边界检查
   | hard_fail
   +----------------------> DEFER_TO_HUMAN
   |
   v
学习式质量分类器
   |
   +-- q_cls < theta_bad ----> DEFER_TO_HUMAN
   |
   +-- theta_bad <= q_cls < theta_good --> QUALITY_UNCERTAIN
   |                                         |
   |                                         v
   |                                  进入疾病 Agent 的升级通道
   |
   +-- q_cls >= theta_good ------> 进入疾病分类
```

`DEFER_TO_HUMAN` 表示建议人工复核，不表示图像一定错误。

## 4. 免费硬筛

硬筛只负责捕获训练分布外的极端异常图像，不承担精细质量判断。

### 4.1 前景比例

对灰度图进行 Otsu 阈值分割，计算非背景区域占比：

```text
q_lf = foreground_pixels / total_pixels
```

建议先使用以下阈值作为占位值：

```text
q_lf < 0.08 或 q_lf > 0.45 -> hard_fail
```

实际阈值必须根据 CheXpert 训练集分布和质量验证集重新校准。应尽量排除黑边、文字和小面积伪影的影响，必要时只保留最大连通区域。

### 4.2 动态范围

将图像统一转换到 8 bit 后，计算 99% 和 1% 分位数差：

```text
q_dr = P99 - P1
```

初始规则：

```text
q_dr < 60 -> hard_fail
```

该阈值同样只能作为占位值。预处理、位深、裁剪和压缩方式改变后必须重新估计。

### 4.3 其他硬检查

- 文件无法读取；
- 图像尺寸低于预设下限；
- 全黑、全白或近似常数图像；
- 非正面视图（如果当前实验只使用 frontal 图像）；
- 明显异常的宽高比或边界填充。

## 5. 学习式质量分类器

### 5.1 模型

第一版使用 ImageNet 预训练或 torchxrayvision 预训练的 DenseNet-121：

- 冻结大部分骨干层；
- 只训练最后的二分类头；
- 若验证集效果不足，再解冻最后一个 Dense Block；
- 输出 `q_cls`，表示“适合自动分类”的概率。

```text
q_cls = P(quality_label = 1 | image)
```

不建议一开始训练完整质量分割网络，因为 CheXpert 没有对应的像素级质量标注。

### 5.2 训练划分

- 患者级划分；
- 训练集、验证集、测试集固定后不可反复调参测试集；
- 使用 5 折交叉验证检查小样本稳定性；
- 训练完成后在验证集上进行温度校准或 Platt 校准；
- `theta_bad` 和 `theta_good` 只能使用验证集确定。

## 6. Agent 决策规则

```python
if hard_fail:
    action = "DEFER_TO_HUMAN"
elif q_cls < theta_bad:
    action = "DEFER_TO_HUMAN"
elif q_cls < theta_good:
    action = "QUALITY_UNCERTAIN"
else:
    action = "ACCEPT_QUALITY"
```

进入疾病分类后，再由疾病 Agent 结合分类置信度和模型分歧作最终路由：

```python
if quality_uncertain:
    action = "CALL_MODEL_2_OR_HUMAN"
elif disease_confidence >= theta_accept and disagreement <= theta_disagree:
    action = "ACCEPT"
else:
    action = "DEFER_TO_HUMAN"
```

阈值目标是高召回识别“不适合自动分类”的图像，允许一定误报。不能直接使用固定的 0.8 置信度阈值。

## 7. 评价指标

### 7.1 质量模块

- AUROC；
- AUPRC；
- 不合格图像召回率；
- 不合格图像精确率；
- 高召回操作点下的误报率；
- Brier score 或可靠性图；
- 医生间一致性（有多名标注者时）。

### 7.2 硬筛

- 极端异常图像检出率；
- 正常图像误拦截率；
- 每类硬筛规则的单独贡献。

### 7.3 对疾病 Agent 的最终价值

比较以下系统：

1. 仅疾病分类模型；
2. 仅固定置信度拒诊；
3. 质量硬筛 + 疾病分类；
4. 质量分类器 + 疾病分类；
5. 完整质控门 + 疾病 Agent。

核心指标：

- 覆盖率-风险曲线；
- 选择性风险；
- 高置信错误率；
- 自动处理比例；
- 人工复核比例；
- 平均第二模型调用次数；
- 在相同覆盖率下的错误率。

最重要的验收标准不是质量分类器 AUC，而是：

> 在相同自动处理覆盖率下，加入质控门后疾病分类的选择性风险下降。

## 8. 主要对照与消融

第一版只保留最必要的实验：

### 对照

- Single：单疾病分类模型直接输出；
- Fixed-Threshold：只用疾病置信度阈值拒诊；
- Proposed-QG：加入硬筛和学习式质量门。

### 消融

- 去掉硬筛；
- 去掉学习式质量分类器；
- 只保留 `q_cls`，去掉疾病不确定性；
- 只保留疾病不确定性，去掉质量状态。

## 9. 风险与降级方案

### 风险一：质量分类器无法稳定训练

降级为技术质量特征 + 规则门控，并将学习式分类器作为探索性结果。

### 风险二：质量与疾病错误没有关系

不能强行保留质量门。应报告负结果，并将研究问题改为“质量状态是否具有条件性路由价值”。

### 风险三：质量模型学习到疾病或设备来源

进行疾病标签分层、AP/PA 分层和数据来源分层分析。必要时在训练中加入分层抽样或重新加权。

### 风险四：医生标注不足

先完成 100 张试标，检查标签定义和一致性，再决定是否扩大到 400–550 张。

## 10. 阶段性完成标准

质控门初版只有在满足以下条件后，才进入多标签疾病分类：

1. CheXpert 图像读取和预处理流程固定；
2. 质量标注规范经导师确认；
3. 硬筛能稳定捕获极端异常图像；
4. 质量分类器在独立测试集上有可解释的结果；
5. 质量门对疾病 Agent 的覆盖率-风险曲线至少不劣于固定置信度拒诊；
6. 完成失败案例分析，确认误报和漏报原因；
7. 没有把结果表述为临床诊断能力或临床部署证明。
