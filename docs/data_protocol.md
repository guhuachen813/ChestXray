# CheXpert 数据协议

## 当前阶段

- 主数据集：CheXpert-v1.0-small（待下载）
- 第一阶段任务：Cardiomegaly 单标签二分类
- 图像范围：只使用 frontal 图像
- 官方 valid：暂作为固定测试集，不用于调参
- 训练内部验证：按 Patient ID 划分

## 标签

CheXpert 标签包含正类、负类、不确定和未提及。当前数据清单脚本只将 0 和 1 作为第一轮有效标签；不确定和空值的最终处理方式需结合统计和导师意见确认。

- 标签数量和类别比例；
- 图像路径完整性；
- 是否存在重复患者或重复研究。
